# Instrument Serif

This directory contains the unmodified Instrument Serif static TrueType face
used for the Yours wordmark and the About page.

- Family: `Instrument Serif`
- Upstream file: `InstrumentSerif-Regular.ttf` (weight 400)
- Source: <https://fonts.google.com/specimen/Instrument+Serif>
- Retrieved: 2026-11-25 from Google Fonts through the Google Fonts CSS API
- SHA-256: `a99e3db50076202713812ed541feeb23ffeebb61db1fa6b1cf48fe590d37ef18`
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt)

Slint embeds the face at compile time through `ui/app.slint`; the interface
falls back to its other bundled and system faces for glyphs Instrument Serif
does not cover.
